# Public résumé asset

To publish a résumé, supply a **publication-approved, general-use** PDF as `public/resume.pdf`.

The site build copies this PDF to `dist/resume.pdf` and exposes direct download links in the résumé and contact pages. Without it, the résumé page contains a concise HTML work history and a contact link instead of a broken PDF link.

The available application-specific résumé files have not been included. Confirm that all claims, metrics and details in the chosen PDF may be publicly distributed before adding it.
