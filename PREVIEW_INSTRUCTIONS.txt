Directory 11 — offline preview

Extract the ZIP and open OPEN_PORTFOLIO.html with a real browser, not a document viewer.

The website is most reliable when served over HTTP/HTTPS. From the source ZIP:

    uv sync
    uv run python scripts/build.py
    uv run python -m http.server 8000 --bind 0.0.0.0 --directory dist

Then visit http://localhost:8000 on desktop, or http://YOUR_LAN_IP:8000 from a phone on the same Wi-Fi network.

The font uses a monospaced fallback stack. No reference-site font files are included.
